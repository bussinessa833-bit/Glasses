# 🕶️ LUXE VISION - Premium Glasses & Sunglasses E-commerce Website

A modern, fully responsive, and feature-rich e-commerce website for premium eyewear. Built with vanilla HTML5, CSS3, and JavaScript. Perfect for hosting on GitHub Pages.

![LUXE VISION](https://images.unsplash.com/photo-1572635196237-14b3f281503f?w=1200&h=400&fit=crop)

---

## ✨ Features

### 🎨 Premium Design
- **Black + White + Gold** luxury color scheme
- Glassmorphism effects and smooth animations
- Responsive grid layouts
- Professional typography and spacing
- Mobile-first design approach

### 🛍️ E-commerce Functionality
- **Product Catalog** - 8+ pre-loaded products with images, prices, and ratings
- **Shopping Cart** - Add/remove products, adjust quantities, real-time totals
- **Wishlist** - Save favorite items for later
- **Search** - Real-time product search functionality
- **Quick View** - Modal preview of product details
- **Product Categories** - Filter by Men's, Women's, Sunglasses, Luxury
- **Countdown Timer** - Special offer timer with real-time updates
- **LocalStorage** - Persistent cart and wishlist data

### 🎯 Interactive Features
- Smooth scroll animations
- Hamburger mobile navigation
- Working search functionality
- Newsletter subscription with email validation
- Back-to-top button
- Toast notifications
- Hover effects and transitions

### 📱 Responsive Sections
1. **Navbar** - Fixed navigation with cart/wishlist icons
2. **Hero Section** - Large banner with call-to-action buttons
3. **Featured Categories** - 4 category cards
4. **Featured Products** - 8 product cards with ratings and actions
5. **Special Offer** - Countdown timer and promotional banner
6. **Why Choose Us** - 4 feature cards
7. **New Collection** - Fashion showcase section
8. **Customer Reviews** - 3 testimonial cards
9. **Newsletter** - Email subscription form
10. **Footer** - Complete footer with links and social media

## 🚀 Quick Start

### Option 1: GitHub Pages (Recommended)
1. Fork or clone this repository
2. Go to Settings → Pages
3. Select "Deploy from a branch"
4. Choose "main" branch
5. Your site will be live at: `https://yourusername.github.io/luxe-vision-ecommerce`
